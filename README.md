# «Академика» — сайт с онлайн-записью

Сайт клиники психиатрии «Академика» (academicals.ru) + система онлайн-записи с
отправкой писем на почту клиники и подтверждением клиенту. Чистый Python (stdlib),
без зависимостей.

## Запуск

```bash
cd ~/academika
python3 server.py            # → http://localhost:8080
python3 server.py -p 3000    # другой порт
```

## Структура

```
server.py          stdlib-сервер: статика + /api/booking + /api/slots
site/              index.html · price.html · kids.html · css/style.css · js/app.js
data/bookings.db   SQLite — все записи
outbox/            .eml-письма (если SMTP не настроен или при ошибке отправки)
config.json        SMTP-настройки (создайте из config.example.json)
```

## Включить отправку писем

1. `cp config.example.json config.json`
2. Заполнить `smtp_host`, `smtp_port`, `smtp_user`, `smtp_pass`, `from_email`
   и `notify_email` — почта клиники, на которую приходят новые записи.
3. Для Gmail/Яндекса нужен **пароль приложения** (не основной пароль):
   Gmail → myaccount.google.com/apppasswords; Яндекс → «Безопасность» → Пароли приложений.

Что происходит при записи:
- письмо с полными данными записи → `notify_email` (почта клиники);
- письмо-подтверждение клиенту (если указан e-mail);
- всё дублируется в `outbox/`, статус каждой записи — в `bookings.db`.

## Логика записи (4 шага в модальном окне)

1. Кому помощь: себе / ребёнку / семье
2. Услуга (детские услуги показываются отдельно)
3. Дата + свободное время (`/api/slots` исключает занятые, интервалы 9:00–18:00)
4. Контакты + согласие на обработку данных → POST `/api/booking`, сервер
   валидирует, сохраняет в SQLite и запускает рассылку писем в фоне.

Слоты: 9:00, 10:30, 12:00, 13:30, 15:00, 16:30, 18:00 — изменить в
`server.py`, список `SLOTS`.

## GitHub Pages / дашборд

Статические страницы опубликованы в `docs/` (копия `site/`) — GitHub Pages
обслуживает их по `/docs`. Онлайн-запись на Pages **не работает** (нет backend):
нужен `python3 server.py`. Дашборд сравнения версий — `docs/dashboard.html`
(открывается офлайн, данные никуда не отправляются).
